# 编写文档（doc-writing）

## 目的

编制用户手册、安装手册、发布手册等项目交付文档。

## 执行者

`release-engineer`（安装/发布手册）、`product-manager`/`ui-developer`（用户手册）

## 输入

- `design/`
- `release/artifact/`
- `pages/prototype/`

## 输出

- `release/manual-install.md`（安装手册）
- `release/manual-release.md`（发布手册）
- `docs/manual-user.md`（用户手册，如需要）

## 手册要求

### 安装手册
- 环境要求（OS、依赖、版本）
- 安装步骤（编号、可复制命令）
- 配置说明（配置项表格：名称/含义/默认值/是否必填）
- 初始化数据
- 验证安装是否成功的方法
- 常见问题（FAQ）与排障

### 发布手册
- 版本信息、commit、构建命令
- 打包产物清单与说明
- 部署步骤
- 回滚方案
- 发布状态标记规则（测试版/生产版）

### 用户手册
- 功能导航（对应模块/功能）
- 操作步骤（配原型截图/说明）
- 常见问题

## 质量要求

- 步骤必须**可照做**：命令可复制、参数说明清楚。
- 配置项用表格，标注必填与否。
- 不写空话，面向操作。

## 检查清单

- [ ] 安装手册含验证方法
- [ ] 发布手册含回滚方案
- [ ] 配置项有表格说明
- [ ] 步骤可复现

## 触发与边界

**该用**：交付物需要给"使用者/运维"照着做时。

**不该用**：需求/设计/评审这类内部交付物（各有专门技能与模版）。

## 常见错误

- 步骤不可照做（命令带占位符未说明、参数缺失）。
- 配置项不标必填与否、无默认值。
- 安装手册不给"如何验证装成功"。
- 发布手册无回滚方案。
